## Extraction & Splitting Rules

1. **Auto-Split Composite Receipts**: If a receipt includes purchases belonging to different categories (for example, a supermarket receipt with pantry coffee and stationery files), split them into separate line items with their respective codes[cite: 1].
2. **Petrol Station Separation**: On petrol station receipts, isolate fuel purchases (`920-0000`)[cite: 1] from snacks, beverages, or car wash purchases.
3. **Accommodation State Identification**: When code `923-0000` is used, extract the location from the receipt and format the detail as `ACCOMODATION - STATE: [STATE NAME]` (e.g., `ACCOMODATION - STATE: SELANGOR`)[cite: 1].
4. **Currency & Totals**: All amounts must be parsed in Malaysian Ringgit (`RM`)[cite: 1] to two decimal places.
5. **Audit Notes Control**: 
   - Keep `audit_notes` strictly as an empty array `[]` if the receipt is legible, calculation math matches, and codes are successfully mapped so that clean submissions auto-verify.
   - Only append a warning string into `audit_notes` if there is a critical anomaly (e.g., blurry image text, missing total, or calculation mismatch) so the Accounts Admin can easily review it.
